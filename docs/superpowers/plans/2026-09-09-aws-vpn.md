# aws-vpn Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `vpn` bash command (picker, toggle, `all`, `status`, `disconnect`, `list`, `prompt`, `logs`, completion) on top of the official `aws-vpn-client` 6.x CLI.

**Architecture:** One bash script `vpn` where every daemon interaction goes through a `cli` wrapper that maps the CLI's error conventions; small helper functions (`profiles`, `active`, `is_active`, `uptime_since`, `region_of`) feed per-command `cmd_*` functions dispatched from a `case`. Tests run the real script against a stub `aws-vpn-client` placed first on `PATH`, whose state lives in files under `$VPN_STUB_DIR`.

**Tech Stack:** bash 4+, jq 1.6+, fzf (optional), GNU coreutils (`date`, `timeout`), shellcheck, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-09-aws-vpn-design.md`

## Global Constraints

- Script header: `#!/usr/bin/env bash` and `set -euo pipefail`.
- Zero sudo, zero own tunnel handling. Only `aws-vpn-client` talks to the daemon.
- Profile names in the daemon ARE the slugs. No mapping table, no config file.
- Order everywhere = `imported-at` ascending from `list-profiles`.
- Output markers: `==>` step, `>` info, `✓` success, `!` warning (stderr), `✗` error (stderr). Colours only when stdout is a TTY and `NO_COLOR` is unset.
- Exit codes: 0 success, 1 error, 130 interrupted.
- Env vars: `VPN_CONNECT_TIMEOUT` (default 180), `VPN_POLL_INTERVAL` (default 0.5), `VPN_LOG_DIR` (default `/var/log/awsvpnclient`), `VPN_NOW` (epoch override for tests), `VPN_NO_FZF` (force `select` fallback), `NO_COLOR`.
- Observed daemon CLI behaviour (real 6.0.1, 2026-09-09): success JSON on stdout exit 0; `{"status":"Error","message":"..."}` on **stderr** exit 1; usage errors as plain text on stderr exit 2; `get-connection-status` returns `NotConnected` for an idle profile, `WaitingForIdentity` / `Connecting` / `Connected` during connect; `connect` returns `{"status":"WaitingForIdentity"}` immediately; `disconnect` prints nothing on success.
- Commit after every task with a conventional-commit message ending in `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Every task ends with `shellcheck vpn test/run.sh test/stub/aws-vpn-client vpn.bash` clean (only files that exist yet) and `bash test/run.sh` green.

Fixed test fixtures (used by several tasks):

- Profiles in the stub are listed in a deliberately scrambled order (`stage, dev, prod-us, prod`) with `imported-at` seconds `02, 01, 04, 03`, so the correct import order is `dev stage prod prod-us`.
- Connections created by the stub or by `connected` carry `last-updated-at` `2026-09-09T09:00:00+02:00` = epoch `1788937200`.
- `VPN_NOW=1788937954` (754 s later) makes uptime `12:34`; `VPN_NOW=1788940817` (3617 s) makes `01:00:17`.
- `config-<slug>` has a `remote` line in `eu-central-1` for all profiles except `prod-us`, which uses `us-east-2`.

`test/stub/aws-vpn-client` (make executable with `chmod +x`):
```bash
#!/usr/bin/env bash
# Stub of the AWS VPN Client 6.x CLI for tests. All state lives in $VPN_STUB_DIR:
#   profiles.json     what list-profiles prints
#   connections.json  what list-connections prints; connect/disconnect mutate it
#   status-sequence   one status per line for successive get-connection-status
#                     calls; the last line repeats forever; optional
#   config-<slug>     what get-config prints for <slug>
#   calls.log         every invocation, one per line
#   fail              when present every call exits 1 with no output
#   error-<cmd>       when present, <cmd> fails with its content as the error message
set -euo pipefail
d="${VPN_STUB_DIR:?VPN_STUB_DIR not set}"
printf '%s\n' "$*" >> "$d/calls.log"
[[ -e "$d/fail" ]] && exit 1

cmd="${1:-}"
shift || true
profile=""
while (($#)); do
  case "$1" in
    --profile-name) profile="$2"; shift 2 ;;
    *) shift ;;
  esac
done

err() {
  printf '{\n  "status": "Error",\n  "message": "%s"\n}\n' "$1" >&2
  exit 1
}
[[ -f "$d/error-$cmd" ]] && err "$(< "$d/error-$cmd")"
has_profile() {
  jq -e --arg p "$1" 'any(.[]; .["profile-name"] == $p)' "$d/profiles.json" > /dev/null
}
is_connected() {
  jq -e --arg p "$1" 'any(.[]; .["profile-name"] == $p)' "$d/connections.json" > /dev/null
}
write_connections() {  # $1 = jq filter applied to connections.json
  local tmp
  tmp=$(mktemp)
  jq --arg p "$profile" "$1" "$d/connections.json" > "$tmp"
  mv "$tmp" "$d/connections.json"
}

case "$cmd" in
  list-profiles)
    cat "$d/profiles.json" ;;
  list-connections)
    cat "$d/connections.json" ;;
  get-config)
    has_profile "$profile" || err "Profile not found"
    cat "$d/config-$profile" ;;
  get-connection-status)
    has_profile "$profile" || err "Profile not found"
    if [[ -s "$d/status-sequence" ]]; then
      status=$(head -n 1 "$d/status-sequence")
      if (( $(wc -l < "$d/status-sequence") > 1 )); then
        sed -i '1d' "$d/status-sequence"
      fi
    elif is_connected "$profile"; then
      status=Connected
    else
      status=NotConnected
    fi
    printf '{\n  "connection-status": "%s"\n}\n' "$status" ;;
  connect)
    has_profile "$profile" || err "Profile '$profile' not found"
    write_connections '. + [{"profile-name": $p, "initiated-by": "test", "connection-status": "Connected", "last-updated-at": "2026-09-09T09:00:00+02:00"}]'
    printf '{\n  "status": "WaitingForIdentity"\n}\n' ;;
  disconnect)
    is_connected "$profile" || err "Profile is not connected"
    write_connections 'map(select(.["profile-name"] != $p))' ;;
  -V|--version)
    echo "aws-vpn-client 6.0.1" ;;
  *)
    echo "error: unrecognized subcommand '$cmd'" >&2
    exit 2 ;;
esac
```

`test/run.sh`:
```bash
#!/usr/bin/env bash
# Test runner for vpn. Runs the real script against test/stub/aws-vpn-client.
# Usage: bash test/run.sh
set -uo pipefail

here=$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)
root=$(dirname "$here")
export PATH="$here/stub:$PATH"
export VPN_CONNECT_TIMEOUT=2 VPN_POLL_INTERVAL=0.05 NO_COLOR=1
export VPN_NOW=1788937954   # 754 s after the fixture timestamp 2026-09-09T09:00:00+02:00

pass=0
fail=0
out=""
rc=0

setup() {
  VPN_STUB_DIR=$(mktemp -d)
  export VPN_STUB_DIR
  # Deliberately scrambled order; import order is dev, stage, prod, prod-us.
  cat > "$VPN_STUB_DIR/profiles.json" <<'EOF'
[
  {"profile-name": "stage",   "owned-by": "t", "auth-type": "saml", "imported-at": "2026-09-09T09:00:02+02:00"},
  {"profile-name": "dev",     "owned-by": "t", "auth-type": "saml", "imported-at": "2026-09-09T09:00:01+02:00"},
  {"profile-name": "prod-us", "owned-by": "t", "auth-type": "saml", "imported-at": "2026-09-09T09:00:04+02:00"},
  {"profile-name": "prod",    "owned-by": "t", "auth-type": "saml", "imported-at": "2026-09-09T09:00:03+02:00"}
]
EOF
  echo '[]' > "$VPN_STUB_DIR/connections.json"
  : > "$VPN_STUB_DIR/calls.log"
  local p
  for p in dev stage prod; do
    printf 'client\nremote cvpn-endpoint-0123.prod.clientvpn.eu-central-1.amazonaws.com 443\n' > "$VPN_STUB_DIR/config-$p"
  done
  printf 'client\nremote cvpn-endpoint-0456.prod.clientvpn.us-east-2.amazonaws.com 443\n' > "$VPN_STUB_DIR/config-prod-us"
}

connected() {  # mark slugs as connected in the stub
  local p
  for p in "$@"; do
    jq --arg p "$p" '. + [{"profile-name": $p, "initiated-by": "t", "connection-status": "Connected", "last-updated-at": "2026-09-09T09:00:00+02:00"}]' \
      "$VPN_STUB_DIR/connections.json" > "$VPN_STUB_DIR/c.tmp"
    mv "$VPN_STUB_DIR/c.tmp" "$VPN_STUB_DIR/connections.json"
  done
}

run_vpn() {  # runs vpn, captures combined output in $out and exit code in $rc
  out=$("$root/vpn" "$@" 2>&1)
  rc=$?
}

calls() {  # invocations of a stub subcommand, e.g. `calls connect` -> "connect --profile-name dev"
  grep "^$1 " "$VPN_STUB_DIR/calls.log" || true
}

assert_eq() {  # actual expected label
  if [[ "$1" == "$2" ]]; then
    pass=$((pass + 1))
  else
    fail=$((fail + 1))
    printf 'FAIL %s\n  expected: %q\n  actual:   %q\n' "$3" "$2" "$1"
  fi
}

assert_contains() {  # haystack needle label
  if [[ "$1" == *"$2"* ]]; then
    pass=$((pass + 1))
  else
    fail=$((fail + 1))
    printf 'FAIL %s\n  expected to contain: %q\n  actual: %q\n' "$3" "$2" "$1"
  fi
}

test_case() {  # label function
  echo "- $1"
  setup
  "$2"
  rm -rf "$VPN_STUB_DIR"
}

# --- cases -------------------------------------------------------------------

t_version() {
  run_vpn --version
  assert_eq "$rc" 0 "version exit code"
  assert_eq "$out" "aws-vpn 0.1.0" "version output"
}

t_help() {
  run_vpn --help
  assert_eq "$rc" 0 "help exit code"
  assert_contains "$out" "Usage: vpn" "help mentions usage"
  assert_contains "$out" "prompt" "help lists prompt"
}

test_case "prints version" t_version
test_case "prints help" t_help

echo
echo "passed: $pass  failed: $fail"
(( fail == 0 ))
```

```bash
#!/usr/bin/env bash
# vpn - fzf picker, toggle and shell-prompt helper on top of the AWS VPN Client 6.x CLI.
# https://github.com/mmh/aws-vpn
set -euo pipefail

VERSION="0.1.0"
CONNECT_TIMEOUT="${VPN_CONNECT_TIMEOUT:-180}"
POLL_INTERVAL="${VPN_POLL_INTERVAL:-0.5}"
LOG_DIR="${VPN_LOG_DIR:-/var/log/awsvpnclient}"

# --- output ------------------------------------------------------------------
if [[ -t 1 && -z "${NO_COLOR:-}" ]]; then
  BOLD=$'\e[1m' DIM=$'\e[2m' RED=$'\e[31m' GREEN=$'\e[32m' YELLOW=$'\e[33m' CYAN=$'\e[36m' RESET=$'\e[0m'
else
  BOLD="" DIM="" RED="" GREEN="" YELLOW="" CYAN="" RESET=""
fi
step()    { printf '%s==>%s %s\n' "$BOLD" "$RESET" "$*"; }
info()    { printf '%s>%s %s\n' "$CYAN" "$RESET" "$*"; }
success() { printf '%s✓%s %s\n' "$GREEN" "$RESET" "$*"; }
warn()    { printf '%s!%s %s\n' "$YELLOW" "$RESET" "$*" >&2; }
err()     { printf '%s✗%s %s\n' "$RED" "$RESET" "$*" >&2; }
die()     { err "$@"; exit 1; }

usage() {
  cat <<EOF
${BOLD}Usage:${RESET} vpn ${DIM}[command]${RESET}

  ${CYAN}vpn${RESET}                      Pick a profile to connect or disconnect
  ${CYAN}vpn${RESET} ${DIM}<profile>${RESET}            Connect, or disconnect if already connected

${BOLD}Commands:${RESET}
  ${CYAN}all${RESET}                      Connect every profile that is not connected
  ${CYAN}status${RESET}                   Show active connections
  ${CYAN}disconnect${RESET} ${DIM}[profile|all]${RESET}  Disconnect one, several (picker) or all  ${DIM}(alias: down)${RESET}
  ${CYAN}list${RESET}                     List profiles                            ${DIM}(alias: ls)${RESET}
  ${CYAN}logs${RESET} ${DIM}[profile]${RESET}           Tail the daemon log
  ${CYAN}prompt${RESET}                   Connection indicator for the shell prompt
  ${CYAN}-v${RESET}, ${CYAN}--version${RESET}            Print version
  ${CYAN}-h${RESET}, ${CYAN}--help${RESET}               This help

Profiles are the names known to ${BOLD}aws-vpn-client list-profiles${RESET}, in import order.
EOF
}

# --- dispatch ----------------------------------------------------------------
main() {
  case "${1:-}" in
    -h|--help)    usage; exit 0 ;;
    -v|--version) echo "aws-vpn $VERSION"; exit 0 ;;
    -*)           usage >&2; exit 1 ;;
    *)            die "not implemented yet" ;;
  esac
}

main "$@"
```

Add to `vpn` after the output section:
```bash
# --- daemon CLI --------------------------------------------------------------
require() {  # require <binary> <hint>
  command -v "$1" > /dev/null 2>&1 || die "$1 not found, $2"
}

# Run aws-vpn-client and print its stdout. The 6.x CLI prints success JSON on
# stdout (exit 0), {"status":"Error","message":...} on stderr (exit 1), plain
# usage errors on stderr (exit 2), and fails without JSON when the daemon is down.
cli_text() {
  local out errfile errtxt msg
  errfile=$(mktemp)
  if out=$(aws-vpn-client "$@" 2> "$errfile"); then
    rm -f "$errfile"
    printf '%s' "$out"
    return 0
  fi
  errtxt=$(< "$errfile")
  rm -f "$errfile"
  if msg=$(jq -er '.message' <<< "$errtxt" 2> /dev/null); then
    die "$msg"
  fi
  die "AWS VPN Client daemon not reachable: systemctl status aws-client-vpn-daemon"
}

cli() {  # like cli_text, but the output must be JSON
  local out
  out=$(cli_text "$@")
  jq -e . <<< "$out" > /dev/null 2>&1 \
    || die "AWS VPN Client daemon not reachable: systemctl status aws-client-vpn-daemon"
  printf '%s' "$out"
}

# --- data helpers ------------------------------------------------------------
profiles() {  # slugs, one per line, in import order
  cli list-profiles | jq -r 'sort_by(.["imported-at"]) | .[]["profile-name"]'
}

require_profile() {  # die unless $1 is a known slug
  local list
  list=$(profiles)
  grep -qxF -- "$1" <<< "$list" \
    || die "Unknown profile '$1'. Available: $(paste -sd' ' <<< "$list")"
}

# --- commands ----------------------------------------------------------------
cmd_list() {
  local act p
  act=$(cli list-connections | jq -r '.[] | select(.["connection-status"] == "Connected") | .["profile-name"]')
  while IFS= read -r p; do
    if grep -qxF -- "$p" <<< "$act"; then
      printf '%s●%s %s\n' "$GREEN" "$RESET" "$p"
    else
      printf '%s○%s %s\n' "$DIM" "$RESET" "$p"
    fi
  done < <(profiles)
}
```

Add to the data helpers section of `vpn`:
```bash
is_active() {  # exit 0 when $1 is connected
  cli list-connections \
    | jq -e --arg p "$1" 'any(.[]; .["profile-name"] == $p and .["connection-status"] == "Connected")' > /dev/null
}

active() {  # connected slugs with their last-updated-at, tab separated, import order
  local conns p
  conns=$(cli list-connections)
  [[ $(jq 'length' <<< "$conns") -gt 0 ]] || return 0
  while IFS= read -r p; do
    jq -r --arg p "$p" \
      '.[] | select(.["profile-name"] == $p and .["connection-status"] == "Connected") | "\(.["profile-name"])\t\(.["last-updated-at"])"' \
      <<< "$conns"
  done < <(profiles)
}

uptime_since() {  # $1 = ISO-8601 timestamp -> MM:SS, or HH:MM:SS from one hour
  local start now secs
  start=$(date -d "$1" +%s 2> /dev/null) || { printf '?'; return 0; }
  now="${VPN_NOW:-$(date +%s)}"
  secs=$(( now - start ))
```

```bash
cancel_connect() {  # SIGINT while waiting: cancel the pending attempt in the daemon
  trap - INT
  echo

  warn "Cancelled connection to $1"

connect_profile() {
  local slug="$1" status region shown="" deadline
  step "Connecting to ${BOLD}${slug}${RESET}"
  cli connect --profile-name "$slug" > /dev/null
  # shellcheck disable=SC2064  # expand $slug now, that is the point
  trap "cancel_connect '$slug'" INT
  deadline=$(( $(date +%s) + CONNECT_TIMEOUT ))
  while :; do
    status=$(cli get-connection-status --profile-name "$slug" | jq -r '.["connection-status"]')
    case "$status" in
      Connected)
        trap - INT
        region=$(region_of "$slug")
        success "Connected to ${BOLD}${slug}${RESET}${region:+ ${DIM}(${region})${RESET}}"
        return 0 ;;
      WaitingForIdentity)
        [[ $shown == *W* ]] || { info "Waiting for browser SSO..."; shown+=W; } ;;
      Connecting)
        [[ $shown == *C* ]] || { info "Establishing tunnel..."; shown+=C; } ;;
      *)
        trap - INT
        die "Connection to ${slug} failed: ${status}" ;;
    esac
    if (( $(date +%s) >= deadline )); then
      trap - INT
      aws-vpn-client disconnect --profile-name "$slug" > /dev/null 2>&1 || true
      die "Timed out after ${CONNECT_TIMEOUT}s waiting for ${slug}"
    fi
    sleep "$POLL_INTERVAL"
  done
}

disconnect_profile() {
  local slug="$1" ts up=""
  ts=$(active | awk -F'\t' -v s="$slug" '$1 == s { print $2 }')
  [[ -n $ts ]] && up=$(uptime_since "$ts")
  step "Disconnecting from ${BOLD}${slug}${RESET}"

  success "Disconnected from ${BOLD}${slug}${RESET}${up:+ ${DIM}(was connected ${up})${RESET}}"
}
```

```bash
pick_from() {  # pick_from <prompt> <line>... ; prints the chosen line, exit 1 when cancelled
  local prompt="$1" choice
```

```bash
  local conns act all total p out=""

      out+="${out:+,}${p}"
    fi
  done <<< "$all"
  [[ -n $out ]] && printf '🔒%s\n' "$out"
```

````markdown
# aws-vpn

`vpn`: an fzf picker, connect/disconnect toggle and shell-prompt indicator on top of the
official `aws-vpn-client` CLI that ships with AWS VPN Client 6.0 and later. The official

OpenVPN binary that 6.x no longer ships.

Linux only for now. No sudo needed: the daemon runs as root, the CLI talks to it over a socket.

## Requirements

- [AWS VPN Client](https://docs.aws.amazon.com/vpn/latest/clientvpn-user/client-vpn-connect-linux.html) 6.0.1 or later, daemon `aws-client-vpn-daemon` running
- `jq`
- `fzf` (optional, for the picker; falls back to a numbered menu)

## Install

```bash
git clone https://github.com/mmh/aws-vpn.git ~/cardlay/aws-vpn
ln -sf ~/cardlay/aws-vpn/vpn ~/bin/vpn          # any directory on your PATH
echo 'source ~/cardlay/aws-vpn/vpn.bash' >> ~/.bashrc
```

Profile names are whatever `aws-vpn-client list-profiles` shows, in import order. Short names
make the tool pleasant, so import your `.ovpn` files under slugs:

```bash
aws-vpn-client import-profile --profile-name dev   --config-path ~/Downloads/dev.ovpn
aws-vpn-client import-profile --profile-name stage --config-path ~/Downloads/stage.ovpn
```

Import in the order you want them listed; `imported-at` has one-second resolution, so leave a
second between imports.

## Usage

```console
$ vpn                       # picker: ● connected (uptime) / ○ not connected, Enter toggles
$ vpn dev                   # connect, or disconnect if already connected
$ vpn all                   # connect everything that is down, one browser login each
$ vpn status                # ✓ Connected to dev (eu-central-1) 12:34
$ vpn disconnect [dev|all]  # one, all, or a picker when several are up   (alias: down)
$ vpn list                  # profiles in import order                     (alias: ls)
$ vpn logs [dev]            # tail the daemon log, filtered by profile
$ vpn prompt                # 🔒all / 🔒dev,stage / nothing
```

Shell prompt example (bash):

```bash
vpn_info=$(vpn prompt 2>/dev/null)
[[ -n $vpn_info ]] && PS1+=" \[\e[1;32m\]${vpn_info}\[\e[0m\]"
```

Environment: `VPN_CONNECT_TIMEOUT` (seconds to wait for a connection, default 180),
`VPN_POLL_INTERVAL` (default 0.5), `VPN_LOG_DIR` (default `/var/log/awsvpnclient`),
`VPN_NO_FZF=1` (force the numbered menu), `NO_COLOR`.

## How it works

`connect` in the 6.x CLI returns immediately with `{"status":"WaitingForIdentity"}` while the
browser login runs in the daemon. `vpn` polls `get-connection-status` and reports:

| `connection-status` | meaning |
|---|---|
| `NotConnected` | idle |
| `WaitingForIdentity` | browser SSO pending |
| `Connecting` | tunnel coming up |
| `Connected` | done |

Anything else is treated as a failure. On timeout or Ctrl-C the pending attempt is cancelled
with `disconnect`. CLI errors arrive as `{"status":"Error","message":"..."}` on stderr with exit 1
and are shown as `✗ message`; a CLI that fails without JSON is reported as the daemon being down.

DNS: the daemon sets the pushed DNS server on the tunnel interface. Per-environment routing
domains (so `*.example.internal` goes to the right tunnel when several are up) are not pushed by
AWS Client VPN; a NetworkManager dispatcher script that calls `resolvectl domain` per interface
does that job and is out of scope here.

## Migrating from aws-vpn-cli

1. Disconnect everything.
2. Re-import the profiles under short names, in the order you want (one second apart):
   ```bash
   aws-vpn-client delete-profile --profile-name NebulaDev
   aws-vpn-client import-profile --profile-name dev --config-path ~/.config/AWSVPNClient/OpenVpnConfigs/NebulaDev
   ```
3. Point `~/bin/vpn` and the `.bashrc` `source` line at this repo.
4. `vpn setup-sudo` artefacts are no longer needed: `/etc/sudoers.d/aws-vpn-cli`,
   `/usr/local/lib/aws-vpn-cli`, `~/.config/aws-vpn-cli`.
````
